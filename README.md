# rbi_merger

Merge RBI 1:25K Esri file geodatabases, delivered as one zip per kabupaten/kota, into a single GeoPackage (`rbi_merged.gpkg`).

Layer names repeat across the zips and features overlap along administrative borders. `rbi_merger.py` merges layers by name and removes the overlap by clipping each zip's features to its own kabupaten/kota boundary.

## Requirements

- Python 3 with `geopandas`, `pandas` and `pyogrio`
- `jq` (optional, for coloured output when printing the manifest)

```bash
pip install -r requirements.txt
```

## Setup

### 1. Download the RBI zip files

Download the RBI 25K data for each kabupaten/kota you need from <https://tanahair.indonesia.go.id>.

### 2. Put the zips in `rbi_zip/`

Place every zip in `rbi_zip/`, one zip per kabupaten/kota. Each zip must contain a file geodatabase (`.gdb`), either at the top level or inside a folder. A zip without a readable `.gdb` is skipped with a warning.

`rbi_zip/` is input only. The script never writes to it.

### 3. Get the kabupaten/kota boundaries

Download the administrative boundary of kabupaten/kota (batas kabupaten/kota) from <https://tanahair.indonesia.go.id> and save it in the project root as:

```
clip_features.gpkg
```

Requirements for the file:

- Polygon features, one row per kabupaten/kota. The first layer in the file is read.
- A text column named **`NAMOBJ`** holding the kabupaten/kota name, for example `Kota Bogor`. This is the only column the script uses.
- It can contain more areas than you have zips. Unused ones are ignored.

## Usage

The workflow has two steps.

### Step 1: `--create-manifest`

```bash
./rbi_merger.py --create-manifest
```

Unzips each zip in `rbi_zip/` into `.unzip/`, skipping zips already extracted. It then writes `.manifest.json`, which lists:

- the geodatabase and layers in each zip
- every unique layer name and the zips it appears in
- `unique_layers`, the full list of unique layer names (last in the file)

Running `./rbi_merger.py` with no flags prints this manifest, coloured if `jq` is installed.

### Step 2: `--merge`

```bash
./rbi_merger.py --merge
```

The first run creates `admin_boundary_map.json` and stops. Open it in a text editor:

- `available_namobj` lists the NAMOBJ values found in `clip_features.gpkg`, for reference.
- `boundary_map` has one key per geodatabase, with an empty value. Fill each value with the NAMOBJ of that geodatabase's kabupaten/kota, copied exactly from `available_namobj`.

```json
{
  "available_namobj": ["Bekasi", "Bogor", "Kota Bekasi", "..."],
  "boundary_map": {
    "KotaBogor/RBI25K_KOTA_BOGOR_KUGI50_20221231.gdb": "Kota Bogor"
  }
}
```

Run `./rbi_merger.py --merge` again. It refuses to run while any value is empty, misspelled, or missing, and lists the problems.

The merge then writes `rbi_merged.gpkg`:

- One layer per unique layer name, combining all zips.
- All geometries reprojected to EPSG:4326, with Z removed and multi-part geometries exploded into simple points, lines and polygons.
- Features clipped to the mapped kabupaten/kota boundary of their own zip, so overlaps between neighbouring zips are removed. Points are kept only if they fall inside the boundary.
- `ADMINISTRASI_*` layers are left out, since the boundaries come from `clip_features.gpkg`.
- A `source_zip` column on every feature.
- `Shape_Length` and `Shape_Area` are dropped because clipping makes them stale.
- Columns whose type differs between zips are stored as text.
- A layer that ends up with more than one geometry type is split into `<layer>_<type>` layers.
- Layers with no features left after clipping are not written.

An existing `rbi_merged.gpkg` is replaced.

## Other options

```bash
./rbi_merger.py --clean            # delete .unzip/ and .manifest.json
./rbi_merger.py --force            # like --create-manifest, but re-extract every zip
./rbi_merger.py --zip-dir PATH     # read zips from another folder
./rbi_merger.py --help
```

`--clean` does not touch `rbi_zip/`, `admin_boundary_map.json`, `clip_features.gpkg` or `rbi_merged.gpkg`.

## Files

| Path | Role |
|---|---|
| `rbi_zip/` | Input zips (not tracked) |
| `clip_features.gpkg` | Input kabupaten/kota boundaries (not tracked) |
| `.unzip/` | Extracted zips, generated (not tracked) |
| `.manifest.json` | Layer manifest, generated (not tracked) |
| `admin_boundary_map.json` | Template generated by `--merge`, filled in by hand (not tracked) |
| `rbi_merged.gpkg` | Output (not tracked) |
